# 📈 Zerodha Clone

A full-stack stock trading platform inspired by Zerodha, built using the MERN stack. Users can view holdings, manage positions, place buy/sell orders, and experience a modern trading dashboard with a responsive UI.

## 🚀 Features

- 🔐 User Authentication (Signup/Login)
- 📊 Interactive Dashboard
- 💼 Portfolio Holdings
- 📈 Positions & Orders Management
- 💸 Buy & Sell Stocks
- 📉 Doughnut & Vertical Charts
- 🔄 RESTful APIs
- 📦 MongoDB Database Integration
- 🎨 Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- React.js
- Material UI
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/subhash1717/Zerodha-Clone.git
```

### Install dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd ../frontend
npm install
```

#### Dashboard

```bash
cd ../dashboard
npm install
```

## ▶️ Run the project

### Backend

```bash
npm run dev
```

### Frontend

```bash
npm start
```

### Dashboard

```bash
npm start
```
